# Toblerone Canvas

Create a new project with Cloud enabled.


Refine the interface to match the attached Toblerone extension more closely. Keep the existing functionality and data model.

The current design must not look like a generic rounded-card SaaS dashboard. Use the extension’s warm off-white canvas, thin warm-grey borders, bold black typography, red uppercase labels, numbered editorial sections, compact controls, and strong grid alignment.

Reduce border radiuses and shadows. Increase typographic contrast. Make ranking numbers, changes, and dates visually prominent. Preserve a clean desktop sidebar layout while making the content feel like a sophisticated expanded version of the extension—not a different product.
